# Imágenes de la app

Suelta aquí tus fotos con estos nombres exactos (jpg, jpeg, png o webp).
Si un archivo no existe, la app muestra la ilustración de montaña en su lugar.

| Archivo      | Dónde se usa                         | Tamaño sugerido |
| ------------ | ------------------------------------ | --------------- |
| `hero`       | Portada del panel (senderista)       | 1080 x 1400 px, vertical |
| `phase-1`    | Tarjeta de la fase 1 (Fundación)     | 1080 x 700 px   |
| `phase-2`    | Tarjeta de la fase 2 (Resistencia)   | 1080 x 700 px   |
| `phase-3`    | Tarjeta de la fase 3 (Dominio)       | 1080 x 700 px   |

Para el héroe deja el sujeto en el lado derecho: el texto del nivel va abajo a la izquierda.
